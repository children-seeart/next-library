# 대표 이미지 (맨 위에서 돌아가는 사진)

이 폴더에 사진을 넣으면 페이지 맨 위에서 **차례로 돌아가며** 보입니다.

## 파일 이름

```
hero-1.jpg
hero-2.jpg
hero-3.jpg
hero-4.jpg
hero-5.jpg
```

- **1번부터 순서대로** 넣어주세요. 중간 번호를 건너뛰면 그 뒤 사진은 나오지 않습니다.
- 4장만 넣으셔도 됩니다. 있는 만큼만 돌아갑니다.
- 한 장만 넣으면 그 한 장이 고정으로 보이고, 아래 점 표시는 사라집니다.
- 한 장도 없으면 회색 자리표시자가 보입니다 (지금 상태).

## 사진 규격

| | |
|---|---|
| 가로세로 비율 | **16:9** 권장 (예: 1920×1080) |
| 가로 크기 | 1600~2000px |
| 형식 | JPG |
| 용량 | 한 장당 **300KB 이하** 로 줄여주세요 |

비율이 달라도 잘려서 채워지지만, 16:9가 아니면 위아래가 잘립니다.

용량을 줄이려면 macOS 미리보기에서 **도구 → 크기 조절**로 가로 1800px,
**파일 → 내보내기**에서 JPEG 품질을 70~80% 정도로 맞추면 됩니다.
